HOW TO RUN (JDK 11 or newer)
1. Open this folder in a terminal (VS Code: Terminal > New Terminal).
2. Type:   javac *.java
3. Type:   java Main
First login: admin / admin123  (use menu choice 3)

Data is NOT saved between runs. To keep data, open QueueManager.java and
change   SAVE_DATA = false   to   SAVE_DATA = true
